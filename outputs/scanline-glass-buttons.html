Scanline Term · UI concept

Glass controls

Матовое тёмное стекло, тонкая мятная кромка и мягкий фосфорный отблеск. Контраст остаётся спокойным, чтобы кнопки не спорили со свечением терминала.

CONTROL SURFACECRT · GREEN PHOSPHOR

Основные действия

Лёгкое стекло для обычных команд, зелёный акцент — для главного действия.

Размер и состояния

Компактный вариант для панелей; состояния видны без потери стеклянной фактуры.

Материал

Полупрозрачная зелёно-графитовая заливка с размытием и тонкой верхней засветкой.

Иерархия

Заливка остаётся сдержанной; яркий лайм сохранён только для главного действия и фокуса.
